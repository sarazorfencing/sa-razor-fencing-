# SA Razor Fencing website

Single-page website for SA Razor Fencing (razor wire and electric fencing).
Everything is in `index.html` (photos are built in, no other files needed).

Phone: 067 534 8511 | Email: sarazorfencing@gmail.com

## Put it live with GitHub Pages
1. Upload these files to a new GitHub repository (index.html must be in the main folder).
2. Repository > Settings > Pages.
3. Under "Build and deployment", set Source to "Deploy from a branch", Branch to "main", Folder to "/ (root)", then Save.
4. Wait 1 to 2 minutes. Your site appears at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
